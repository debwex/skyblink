# SKY BLINK — See it. Hear it. Find it.

**NASA Space Apps Challenge 2026 · Challenge: Planet X and SPHEREx · Team Kepler 16 (Miri, Malaysia)**

SKY BLINK is a free website for exploring how the sky changes, using real images from NASA's SPHEREx mission. You can see the changes and you can hear them.

**Live website:** https://debwex.github.io/skyblink/

## What it does
- **Search the sky:** search any star by name or RA/Dec. SKY BLINK "blinks" SPHEREx images taken months apart and marks anything that moved or changed brightness. Gaia DR3 and AllWISE overlays show which objects are already known.
- **Spectrum fingerprint:** each object's infrared light from 0.75 to 5 µm, with water and methane bands marked. You can view it as dots or a line, and listen to it as sound.
- **Listen mode:** a sound tour with spoken descriptions, so blind and low-vision users can hear the sky change. Includes the "Sonar challenge".
- **Planet X Hunter:** real SPHEREx images of Pluto and Makemake moving across fixed stars. Positions come from JPL Horizons. Pluto moves about 5′ in 17 days.
- **Learn and Classroom:** short lessons and activities.

## Challenge test targets (real SPHEREx results)
Epsilon Indi B shows a methane dip. RW Aurigae is about 21% brighter in Feb 2026 than in Sep 2025. Barnard's Star is steady. WISE 0855 is not detected, because it is too faint for SPHEREx. R Draconis saturates the images, because it is too bright.

## Live search helper (Python)
The website shows saved real searches. To search **any** position live, run the helper:
```
pip install astropy astroquery numpy scipy pillow reproject
python python/skyblink_server.py
```
Put `skyblink_server.py` next to a `web` folder that contains this website, then open http://localhost:8000. See `python/HOW_TO_RUN.txt` for details.

## Data
- **NASA:** SPHEREx Data Release 1 (NASA/IPAC IRSA), AllWISE (NASA/IRSA), JPL Horizons.
- **Partners and others:** ESA Gaia DR3; CDS Strasbourg (Sesame name resolver, Aladin Lite).
